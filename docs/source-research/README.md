# Source & Architecture Research

Use this directory for structured study notes about external systems and architectural patterns.

Primary topics include mature Agent Runtime designs, Claude Code architectural concepts, tool systems, permission models, context construction/compaction, session resume, checkpoints, hooks, MCP integration, task/sub-agent models, and failure recovery.

## Legal and engineering rule

External source material is research input, not automatically an implementation dependency. For reconstructed or leaked proprietary code, record only architecture observations and independently implement concepts. Do not copy or vendor source unless a valid license explicitly permits it.

Every external project note should record:

- Repository/project URL and date inspected.
- License status.
- What problem it solves.
- Relevant architecture/components.
- What is reusable directly, reusable only conceptually, or unsuitable.
- Risks and unresolved questions.
