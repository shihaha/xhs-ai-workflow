# 来源代码审计基线

## 教程来源

- HTML：`D:\edge download\大二开公司、从没上过班，我是怎么用406亿Token搭了一套 (2026_8_17 15：56：48).html`
- 需求雷达附件：`需求雷达-分享版.zip`
- 内容系统附件：`内容系统-分享版.zip`

## 初步复用结论

| 来源 | 结论 | 处理方式 |
|---|---|---|
| 需求雷达 SQL、评分与深挖校验脚本 | 高价值 | 复制到测试夹具中理解行为，再以 Windows/Python 服务重写并保留公式证据 |
| 真机采集 Bash/Ego 脚本 | 高价值但平台不兼容 | 保留流程与解析规则，控制层改为 adbutils/uiautomator2 |
| Obsidian 看板插件 | 有界面与模型参考价值 | 复用信息架构，不把 Obsidian 作为运行依赖 |
| 内容采集、笔记身份、质量与评论脚本 | 高价值 | 迁移核心规则并补契约测试 |
| 模板、Agent 提示词与审核流程 | 高价值 | 作为版本化模板导入，演示产品与演示结果不进入生产数据库 |
| 演示笔记、演示 SVG 与演示产品 | 仅测试夹具 | 必须显式标注 fixture，不能在正式页面冒充真实数据 |

## 外部仓库策略

- `xpzouying/xiaohongshu-mcp`：主候选网页适配器。
- `jackwener/xhs-cli`：备用 CLI/JSON 适配器。
- `NanmiCoder/MediaCrawler`：采集与签名处理候选，也可直接集成。
- `openatx/uiautomator2` 与 `openatx/adbutils`：安卓主控制层。
- 所有第三方实现必须包在统一适配器后，并通过同一组契约测试。

## 实机采用门槛

每个候选适配器都记录：安装命令、Windows 启动结果、登录方式、搜索结果、账号结果、原始数据留存、Cookie 失效表现、错误分类和卸载/替换方法。未完成本机 smoke test 的候选只能标记为“未验证”。
