#### `references/original-tutorial/406亿Token教程/教程正文整理版.md`

这是早期生成的**摘要/整理版**，包含总结和改写，只用于快速理解；不得作为逐字原文证据，也不得覆盖 `原文逐字可读版.md`。

#### 原始 SingleFile HTML 的归档状态

当前 GitHub 中**尚未物理保存 2.3MB 原始 SingleFile HTML 本体**。原因是当前 ChatGPT → GitHub 连接器的写入接口接收 UTF-8 字符串而不是本地文件路径；把包含大量 base64 资源的 2.3MB HTML 全量塞进会话再写入，会显著浪费上下文并有截断风险。

因此必须区分：

- `原文逐字可读版.md`：正文内容的直接可读来源，已经入库；
- 原始 HTML：最终无损档案，仍需要通过本地 Git / 可直接访问该源文件的 Codex 工作区物理提交；
- 在原始 HTML 真正出现于仓库前，不得声称“原始 HTML 已归档”。

如果后续需要核对截图、页面视觉、HTML 结构或内嵌资源，应以原始 HTML 为最终来源；建议同时从原始 HTML 抽取图片到独立 assets 并建立图片索引，方便 AI 直接查看。

## 使用规则

- 需要知道“教程原文怎么说”时，读 `406亿Token教程/原文逐字可读版.md`；不要用摘要版冒充原文。
- 需要快速理解教程时，可以读 `教程正文整理版.md`，但重要判断要回到逐字版。
- 需要知道两个分享版的具体实现时，应优先读取未来完整解压入库后的原始文件；在完整文件尚未入库前，`REFERENCE_DIGEST.md` 只能作为导航和摘要。
- 参考资料是**来源快照**，不是生产实现；任何修改主系统的动作都要回到当前代码、UAT 和 handoff 核验。
- 不从参考资料中复制 Cookie、Token、API Key 或个人认证状态到生产代码/文档。
- 参考资料来自用户提供的私有材料；仓库应保持 private，除非权利和公开范围已经单独确认。
