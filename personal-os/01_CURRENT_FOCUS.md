# CURRENT FOCUS

## 当前唯一主战场

**把小红书虚拟产品工作台 V1 收口到“可用于第一轮真实业务实验”的状态。**

现在还不是正式跑选品业务实验的阶段。当前先把工作台做到：

> 不依赖临时手工补数据库、不依赖 Codex 在中间救场，用户可以从界面完成一条真实证据链到 ZIP 的最小闭环。

这叫 **Business-Ready（业务可用）**，不是“所有功能都做完”，也不是“软件永远没有 Bug”。

---

## 本轮 7 天冲刺

**周期：2026-08-20 ～ 2026-08-26**

### 唯一核心结果

到 8 月 26 日前，把工作台至少收口到以下状态：

```text
真实千帆 8/8
→ 真实榜单账号
→ 真机店铺商品深度证据 N/N
→ 同账号公开笔记
→ 百炼文本分析成功并写入 Opportunity
→ 创建产品 / 内容
→ 图片与视觉建议
→ 人工审核
→ 导出 ZIP
```

并且至少完整跑通 **1 次真实端到端 UAT**。

### Business-Ready 完成条件

以下条件同时满足，才允许进入“第一轮真实业务实验”：

- [x] 千帆 8/8 真实采集已经可运行；
- [x] 账号公开资料 / 笔记只读链路已经有 live 证据；
- [x] 百炼图片与视觉分析已有 live 证据；
- [ ] 真机商品 2/2 深度证据验证真正通过，不再停在 `product_evidence_verification_pending`；
- [ ] 百炼文本分析不再因 `AnalysisOutput` 严格校验失败而报 `model_output_invalid`；
- [ ] 同一真实账号可以从榜单 → 店铺 → 笔记 → 分析 → Opportunity 连起来；
- [ ] 后半段产品 → 内容 → 图片 → 人工审核 → ZIP 用真实证据完整成功一次；
- [ ] 上述闭环可以由正常工作台流程触发，而不是靠手工改数据库或临时脚本拼接。

### 这轮不要求完成

- 7×24 小时稳定性验证；
- 多账号 / 多设备；
- 自动发布、点赞、评论、收藏；
- SaaS、多租户；
- 原生 Obsidian；
- 完整视频研究流水线；
- PersonalOS 软件化；
- 漂亮但不影响业务闭环的 UI 重做。

这些属于 **Release-Ready / 后续增强**，不能阻塞第一轮业务学习。

## 改变主线的条件

只有以下情况允许改变：

1. 已经达到 Business-Ready，正式进入业务实验；
2. 出现明确外部硬阻塞，且短期无法继续；
3. 出现重大合规 / 账号 / 技术风险；
4. 用户主动重新决定方向。

“这个功能以后可能有用”“这个 UI 还能更漂亮”“又发现一个新框架”都不是换主线条件。
