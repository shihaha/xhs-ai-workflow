# SOMEDAY / MAYBE

> 有兴趣，但现在明确不做。
>
> 这个文件的作用不是保存“未来一定要做的任务”，而是让大脑放心：我没有忘，但我现在不用动手。

## 当前规则

以下类型默认先进入这里，而不是当天执行：

- 新赚钱项目；
- 新 AI 工具；
- 新 Agent 框架；
- 新 GitHub 仓库；
- 想重做的 UI；
- 想提前开发的自动化；
- 当前主线之外的新产品方向；
- “以后可能有用”的功能。

## 当前 Someday

- [ ] PersonalOS 数据库 —— 只有 Markdown 明显失控后再评估。
- [ ] 更复杂 Hermes 自动化 —— 先观察哪些动作真实重复。
- [ ] 多 Agent 个人管理 —— 当前明确不做。
- [ ] 当前主线之外的新业务方向 —— Weekly Review 再看。

---

## 从 Someday 启动项目的门槛

必须同时满足：

1. 当前主线已经完成 / 明确暂停；
2. 这件事现在仍然重要；
3. 可以写出 7 天内的唯一可见结果；
4. 愿意明确放弃其他竞争项目；
5. 不是因为一时兴奋。
