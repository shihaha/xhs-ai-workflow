> 当前分支：`feature/seven-sins-content-system-v1`
> 当前状态：**产品事实库与关键词种子已开始建立；实时小红书对标采集尚未执行。**

## 1. 系统边界

本目录只负责 D — 内容系统，不负责：

- 修改七宗罪测试产品本体；
- 商品上架、支付、授权码或交付系统；
- 自动发布小红书内容；
- 伪造对标笔记、互动数据或市场表现。

## 5. 内容事实红线

### 可以说

- 这是一个七宗罪主题的互动测试；
- 有基础版与“七宗罪 VS 七美德”对照版；
- 基础版会输出主导倾向、七宗罪分布、触发因素与平衡建议；
- 对照版会输出七宗罪之首、七美德之首、十四维对照雷达与平衡建议；
- 用于娱乐和自我觉察。

### 当前不能说

除非后续有真实证据，否则内容不得宣称：

- 专业心理测评 / 临床心理测试；
- 科学验证、心理学权威认证；
- “准确率 XX%”“比 MBTI 更准”等未经证实结论；
- 可诊断人格、精神疾病、恋爱风险或未来行为；
- 虚构用户评价、销量、转化率或测试人数。

## 6. 当前工作顺序

1. 固化产品事实库；
2. 生成 10～20 个对标搜索关键词种子；
3. 实时采集达到门槛的对标笔记；
4. 一次拆一篇；
5. 聚类；
6. 同类 >=3 篇后形成模板草案；
7. 人工确认后固化 `SKILL.md`；
8. 再开始日更内容生产与审查。
