# 七宗罪测试 — 关键词布局 V0

> 目标：把产品画像翻译成“小红书对标采集用关键词网”。
>
> 状态：**seed / 未经实时搜索验证**。这些词只表示“值得搜”，不表示有流量、能成交或已被验证。

## 1. 搜索原则

- 第一轮控制在 10～20 个词；
- 先覆盖主词、人群/情绪、场景、疑问/决策、对比/替代；
- 不因为产品叫“七宗罪”就只搜七宗罪；
- 既要找直接竞品，也要找能触发“我也想测”的相邻内容；
- 采集后优先看：标题结构、封面、正文骨架、互动、评论里真实想测/求链接/讨论结果的信号；
- 不把高点赞自动等同于高转化。

## 3. 第一轮采集分组

### A 组 — 直接竞品

优先搜：

1. 七宗罪测试
2. 七宗罪人格测试
3. 七宗罪心理测试

目的：确认有没有直接在卖/引流同类测试的账号，以及直接竞品如何描述产品。

### B 组 — 测试大盘

优先搜：

1. 性格测试
2. 人格测试
3. 趣味测试
4. MBTI 测试

目的：拆成熟测试内容的标题、封面、结果展示与互动机制。

### C 组 — 强好奇钩子

优先搜：

1. 测测你是哪种人
2. 隐藏人格测试
3. 人格阴暗面测试
4. 测试你最真实的一面

目的：验证“身份标签 + 隐藏面 + 反差”是不是有效的内容入口。

### D 组 — 社交场景

优先搜：

1. 情侣测试
2. 朋友测试

目的：判断是否值得做“互测/对比/发给朋友”模板。

### E 组 — 单维度系列化

优先搜：

1. 测试你的欲望
2. 测试你的嫉妒心
3. 测试你的脾气
4. 七美德测试

目的：判断是否可以把七宗罪/七美德拆成长期系列，而不是每篇都直接卖完整测试。

## 4. 采集后需要记录的字段

每篇对标至少记录：

- 来源关键词；
- 笔记标题；
- 作者/账号；
- 发布时间；
- 点赞、收藏、评论（以采集时可见数据为准）；
- 封面截图/图片；
- 正文；
- 是否存在明确 CTA；
- CTA 是评论、私信、主页、商品还是直接链接；
- 评论区是否出现“求测试/求链接/我也想测/结果讨论”等购买或使用意图；
- 是否为直接竞品；
- 备注：内容角度、标题公式、封面结构。

## 5. 研究判定

### 可以进入单篇拆解

- 笔记是真实采集；
- 互动达到当前采集门槛；
- 与本产品的获客逻辑有明确关系；
- 正文/图片资料完整到足以拆解。

### 不能直接固化模板

- 只有 1～2 篇相似内容；
- 只看标题没有正文/视觉；
- 互动高但完全没有“想测/讨论结果/点击”的信号；
- 只是泛心理鸡汤，与测试产品关联很弱。

同类至少有 3 篇真实对标后，才允许形成模板草案。
