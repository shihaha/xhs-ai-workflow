# 七宗罪测试 — 内容角度假设 V0

> 这些不是“已验证模板”，只是用于指导对标采集和后续聚类的假设。任何方向都必须等真实小红书对标回来后再决定是否保留。

## H1 — 结果身份型

核心钩子：

- “七宗罪里，你最像哪一种？”
- “你的主导倾向可能不是你以为的那一个”

要验证：

- 身份标签型标题是否更容易点击；
- 用户是否愿意在评论区公开自己的结果；
- 结果截图是否比纯文字更能激发“我也想测”。

产品可承接事实：主导倾向、七宗罪分布。

## H2 — 隐藏面 / 反差型

核心钩子：

- “你以为自己很克制，结果最高的是……”
- “你身上最容易被忽略的那一面”

要验证：

- “隐藏人格/阴暗面/真实一面”是否是高互动搜索与内容角度；
- 暗黑审美是否增益点击还是缩小受众。

产品可承接事实：七宗罪倾向分布、主导倾向。

风险：不得把结果包装成专业人格诊断。

## H3 — 七宗罪 VS 七美德反差型

核心钩子：

- “你身上的罪和德，哪一边更强？”
- “我以为自己是暴怒，结果美德最高竟然是耐心”

要验证：

- 双结果是否比单结果更有分享价值；
- “反差”是否能形成更强封面；
- 用户是否更愿意讨论罪德组合，而不是单一分数。

产品可承接事实：七宗罪之首、七美德之首、十四维雷达。

## H4 — 单维度连续剧型

每篇只讲一个大众化问题：

- 嫉妒：看到别人轻松得到你想要的东西时
- 暴怒：被冒犯后会不会反复回想
- 懒惰：是懒还是启动成本太高
- 暴食：即时满足有多难拒绝
- 傲慢：别人忽略你的贡献时
- 贪婪：为什么总觉得“还不够”
- 色欲：心动和长期选择是否容易混在一起

要验证：

- 单维度是否比“七宗罪全家桶”更容易做系列；
- 哪几个维度大众讨论度最高；
- 哪些维度存在平台表达风险，需要换成更生活化语言。

## H5 — 朋友 / 情侣互测型

核心钩子：

- “发给你最熟的人，看你俩谁的结果更离谱”
- “情侣一起测，最容易吵起来的是哪一项？”

要验证：

- 双人/社交传播是否真的存在；
- 评论区是否出现“@朋友/对象”“发给他测”等行为；
- 是否比个人自测更有转化。

风险：不能宣称结果能判断感情质量或恋爱风险。

## H6 — 先做一道题 / 轻互动型

内容不直接介绍产品，而是先给一道高度相关的情境选择题，让用户选 A/B/C/D，再引导到完整测试。

要验证：

- 轻互动题是否提高评论；
- 评论高是否真的带来测试意图；
- 哪种题目最适合做封面和首屏。

产品可承接事实：产品本身就是连续情境题测试。

## H7 — 结果截图展示型

直接用真实结果页视觉做内容主体：

- 主导倾向卡
- 七宗罪分布
- 罪德双首
- 十四维雷达

要验证：

- 真实结果截图是否比重新设计的信息图更可信；
- 哪张结果模块最适合当封面；
- 用户是否会因为“想拿到这种结果图”而产生测试意图。

## H8 — 克制型自我觉察

不强调“准不准”，而强调：

- “不是给你贴标签，只是看看哪些倾向在特定情境里更容易冒出来。”

要验证：

- 更克制的表达是否降低用户防备；
- 是否会牺牲点击；
- 哪类受众更喜欢这种风格。

## 当前优先验证顺序

1. H1 结果身份型
2. H3 罪德反差型
3. H6 轻互动型
4. H7 结果截图展示型
5. H2 隐藏面/反差型
6. H5 朋友/情侣互测型
7. H4 单维度连续剧型
8. H8 克制型自我觉察

排序只是当前研究优先级，不代表效果排序。
